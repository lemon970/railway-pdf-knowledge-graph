# AI 辅助使用规则

## 本节小结

AI 可以生成候选内容、代码草稿和问题变体，但不能代替规程核对。所有进入正式数据集的数值、单位、条件、页码和技术结论必须由成员确认。

## 可以使用 AI 的工作

- 清理 OCR 中明显的断行和格式问题；
- 从已提供原文中提出候选实体和关系；
- 解释 Git、Neo4j、Python 或前端基础概念；
- 生成脚本初稿、测试用例和自然语言问题变体；
- 检查 CSV 格式和重复项。

## 必须人工完成的检查

- 将 OCR 文本逐项对照 PDF 页面；
- 确认数值、正负号、小数点、单位和适用条件；
- 确认部件名称和专业术语；
- 确认 PDF 页码与印刷页码；
- 判断实体、关系和问题答案是否符合原文。

AI 产生的数据先标记为 `draft`。未经复核不得改为 `reviewed` 或 `approved`。
