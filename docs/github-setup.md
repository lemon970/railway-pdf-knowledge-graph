# GitHub 初始设置清单

## 本节小结

本地仓库无法自动创建 GitHub Project 和里程碑。仓库推送后，组长按本清单完成一次网页设置，成员即可认领任务。

## 仓库设置

- 邀请四名成员加入仓库；
- 默认分支设为 `main`；
- 为 `main` 开启 Pull Request 合并保护；
- 至少需要一名成员审批；
- 禁止强制推送；
- 合并后自动删除功能分支。
