# 项目范围

## 本节小结

第一阶段只处理轮对轴箱装置的五个小节。数据量不足时由组长创建单独 Issue 扩展范围，成员不得自行从其他章节混入数据。

## 纳入范围

| 编号 | 内容 | 主要产出 |

## 证据要求

每条实体和关系至少记录：

- PDF 阅读器显示页码；
- 规程印刷页码；
- 支持该知识的原文；
- 录入人和复核状态。

扫描版 PDF 没有可靠文本层，OCR 只作为录入辅助，最终以页面图像为准。
