# OCR 工作区

## 小结

本目录只保存可追溯的OCR文本和人工修订稿。页面图片、OCR临时缓存和原始PDF不进入Git，原始OCR结果不能直接作为已审核知识导入。

## 文件约定

- `*-raw.txt`：机器原始识别结果，只允许追加说明，不覆盖原内容；
- `*-raw.json`：运行参数、页码、行数和耗时；
- `*-reviewed.txt`：逐页对照扫描页后的人工修订稿；
- `tmp/`、`images/`：本地页面图和临时文件，已被Git忽略。

每页用 `===== PDF_PAGE N =====` 分隔。人工修订稿还要记录印刷页码，确保后续CSV中的双页码能够回查。
